# Checklist do PjBL (extraído do documento da professora)

Marque cada item somente quando estiver implementado, demonstrável e testado.

## Parte A — Fundamentos POO (70%)
- [ ] 1. Encapsulamento em classes.
- [ ] 2. Pelo menos 5 classes.
- [ ] 3. Pelo menos 1 classe abstrata.
- [ ] 4. Pelo menos 1 método abstrato.
- [ ] 5. Ao menos 10 atributos e 10 métodos no total.
- [ ] 6. Ao menos 2 relações de herança.
- [ ] 7. Sobrescrita de método **concreto** herdado (implementar método abstrato não basta).
- [ ] 8. Chamada polimórfica.
- [ ] 9. Associação entre classes.
- [ ] 10. Coleção de objetos (ex.: ArrayList).

## Parte B — Recursos complementares (20%)
- [ ] 11. Classe que estende `Exception`.
- [ ] 12. Interface gráfica.
- [ ] 13. Leitura de arquivo CSV ou TXT.
- [ ] 14. Salvar e recuperar objetos persistentes.

## Parte C — Recursos organizacionais (10%)
- [ ] Repositório GitHub com colaboradores e commits.
- [ ] Kanban no Trello com tarefas atribuídas por pessoa.
- [ ] Fluxograma/diagrama simples adicionado ao Trello.

Fonte: `Requisitos PjBL (1).pdf`, fornecido na conversa. O checklist não é evidência de implementação.
